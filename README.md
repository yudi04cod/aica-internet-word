An entry for the make.fun competition "The Internet in One Word". The
program writes a single word — the word that describes the whole
internet — to `/output/entry.txt`.

The word is **unhinged**: one adjective, eight letters. It is funny on
its own, it says something true about the internet as a whole (millions
of strangers shouting into the same room at once), it is not the first
obvious word anyone reaches for, and it lands in one beat.

Referral code: 38m33ybw

## Run

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` (creating `/output` if
needed). The output is deterministic: byte-identical on every run.
Python 3.13, standard library only, no network access.
